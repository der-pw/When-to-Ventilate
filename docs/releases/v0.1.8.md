# v0.1.8

Makes it easier to see which rooms need ventilation and use them in notifications
and automations.

Added

- The global room-count sensor now exposes `recommended_rooms` with room names
  and `recommended_area_ids` with their stable Home Assistant Area IDs.
- Both lists contain only rooms currently recommended for ventilation and are
  empty when no room is recommended.

Changed

- Documented the new attributes with an example notification template.
- Updated installation instructions for direct installation from the Marketplace
  catalog, with HACS guidance for older supported Home Assistant versions.

Validation results for the release commit are recorded in the GitHub Release.
